the toolkit

the same capabilities forkie has in slack.

💬

chat, in slack

mention it or DM it, in channels, threads, or assistant threads. it follows the conversation.

🖥️

sandboxed code

every conversation gets an isolated linux sandbox — run code, process files, build things.

🌐

web search

current info, docs, and facts — no guessing at recent events.

🐙

github

forks repos, makes edits, opens pull requests. real work in public repos.

🎨

image generation

generate images from a prompt, right in the thread.

📁

files & media

upload anything — audio, video, images, docs — and it'll process and return results.

⏰

reminders

one-time and recurring reminders, or scheduled scripts that run in its sandbox.

🚀

deploys sites

builds static sites and publishes them to a live URL. yes, like this one.

📝

docs & canvases

creates canvases, summaries, runbooks, and structured notes you can keep.

🧭

browser automation

drives a real browser — fills forms, clicks, screenshots, tests web apps.

📧

email

has its own inbox — reads, replies, and sends mail.

♻️

open source

AGPL-3.0, a fork of kyto. run your own, or fork it again.
